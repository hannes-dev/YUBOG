# <ins>On the Subject of Wires</ins>

<f>Wires are the lifeblood of electronics! Wait, no, electricity is the lifeblood.
Wires are more like the arteries. The veins? No matter...</f>


- A wire module can have 3-6 wires on it.
- Only the <ins>one</ins> correct wire needs to be cut to disarm the module.
- Wire ordering begins with the first on the top.
<br/>
<br/>

|                                                                                                                                                                                                                                                                                                                                                                                                                 |
|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <ins>**3 wires:**</ins> <br/>If there are no red wires, cut the second wire.<br/>Otherwise, if the last wire is white, cut the last wire.<br/>Otherwise, if there is more than one blue wire, cut the last blue wire. <br/>Otherwise, cut the last wire.                                                                                                                                                        |
| <ins>**4 wires:**</ins> <br/>If there is more than one red wire and the last digit of the serial number is odd, cut the last wire.<br/>Otherwise, if the last wire is yellow and there are no red wires, cut the first wire.<br/>Otherwise, if there is exactly one blue wire, cut the first wire.<br/>Otherwise, if there is more than one yellow wire, cut the last wire.<br/>Otherwise, cut the second wire. |
| <ins>**5 wires:**</ins> <br/>If the last wire is black and the last digit of the serial number is odd, cut the fourth wire.<br/>Otherwise, if there is exactly one red wire and there is more than one yellow wire, cut the first wire.<br/>Otherwise, if there are no black wires, cut the second wire.<br/>Otherwise, cut the first wire.                                                                     |
| <ins>**6 wires:**</ins> <br/>If there are no yellow wires and the last digit of the serial number is odd, cut the third wire.<br/>Otherwise, if there is exactly one yellow wire and there is more than one white wire, cut the fourth wire.<br/>Otherwise, if there are no red wires, cut the last wire.<br/>Otherwise, cut the fourth wire.                                                                   |
